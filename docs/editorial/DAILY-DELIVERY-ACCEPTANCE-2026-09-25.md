## Bounded visual repair

The next implementation permits one illustration edit per media job after a known
visual failure. It first identifies exactly one defective image; multiple defective
images still stop. The original three versions and all verdicts remain. A durable
edit stage saves its raw output, independent final review is mandatory, and replay,
rejected output or uncertain timeout cannot buy a second edit. Insufficient runtime
yields saved work before making a provider request. Photography is never synthesized
through this repair. This is not permission to bypass a visual gate.
