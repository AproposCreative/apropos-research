## Implemented

- Existing preflight checks retained: ownership, revision/content, protected prose,
  section, canonical hash, decoded immutable style/subject bytes, reference order,
  original user-photo bindings and prior failed attempts. Complete inputs now allow
  **one reviewed attempt** if the actual host can receive the full text and images.
- Missing host delivery still stops. A complete server snapshot is not proof of
  native dispatch. `inputObservation=unavailable` and
  `exactPromptExecutionVerified=false` remain explicit. The optional report
  `inputMode` distinguishes supplied explicit arguments from conversation context.
- Existing native import now stages valid generated originals **privately**, not
  in Webflow or article fields. Same request recovers the same private file.
  Already-staged generated bytes cannot be relabeled as a user photo.
- Existing inline/external preview shows the actual private thumbnail separately
  from article media. Only its authenticated personal **Brug dette billede** action
  creates a file-SHA/revision/content-bound selection and resumes the original
  durable upload/attachment operation. No publication consent is implied.
- Lost storage/attachment replies recover via original bytes, immutable receipts
  and stable IDs. A second image click is unnecessary after completed selection.
  Changed prose, ownership, bytes, versions, missing preview and forged approval
  fields fail closed. No automatic generation/retry or approved-image replacement.
- A cached older chat card cannot select an unseen candidate: the UI-only action
  additionally requires the rendered candidate hash. Older clients must refresh
  tools/cards or use the existing authenticated external preview, not click blind.
- Genuine user-upload/press photos and historical attached replays remain intact.
  No article prose, research, byline, SEO, provider allowance or hold is changed.

Core changes: native-image-integration, image-preflight, image-generation-evidence,
chat-image-brief/import, generated-image-candidate, submissions/image-selection/
