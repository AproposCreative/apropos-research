## V45 candidate

Server-managed HTML/plain signature uses tracked original
`public/images/apropos-newsletter-logo.png`. Production HTTPS bytes match local
file (HTTP 200, image/png, 7673 bytes), visually inspected on white. Existing
Liv signature stays separate. Central editing is in `signature.ts` for Frederik
and the existing Liv settings; no arbitrary model-authored HTML or replacement
logo. Changing a signature invalidates pending approval until a new draft is saved.

Per-mail CC/BCC/to, no default BCC. BCC is only in SMTP envelope, never outbound
MIME headers. A **private IMAP draft** keeps its BCC header for Apple Mail editing;
that draft is never passed raw to SMTP. SMTP builds a separate BCC-free MIME once.
Private immutable outbound MIME is retained for archive-only recovery.

One-way Drafts sync is explicit, versioned and conflict-controlled. Exact UID,
UIDVALIDITY and SHA256 are checked before replacing/removing a draft; UIDPLUS
is mandatory for scoped cleanup, never mailbox-wide EXPUNGE. Old MIME versions
remain in private operation records. Timeout replay performs readback/cleanup,
not another APPEND. External edits/deletions block MCP send and sync. No two-way
merge, external-send detection or prevention of a human concurrently sending
from Apple Mail; use one sending client at a time. Sent draft cleanup is reported
separately; a cleanup failure cannot resend SMTP.

Preview shows private CC/BCC, actual signature, editor, bounded RFC thread,
explicit Drafts export, and separate approval/SMTP/IMAP/delivery receipts.
After a lost acknowledgment it polls read-only status automatically (bounded).
This updates the open MCP widget; it is not an unsolicited assistant message or
a guarantee that a closed chat receives a notification. No automatic mail sender
or recurring task was added. Accreditation keeps its existing dedicated widget.

New tools: compose_editorial_mail, sync_editorial_draft,
get_editorial_mail_thread, repair_editorial_sent. save_editorial_reply accepts
optional to/cc/bcc; sender remains account-bound. Preview resource is mail-reply-v2.
No attachment sending, automatic BCC preference or mailbox-wide search added.
Threads are bounded to six messages per folder and report truncation.

114 targeted tests, TypeScript and scoped lint passed before release; local
browser tests cover mobile/desktop, signature, recipient edits, lost ack,
double-click, expired/missing tokens and inert incoming HTML. Cross-client
Outlook/Gmail rendering and a real V45 send remain unverified until actual tests.
Build reported existing dependency advisories; an extra audit request returned
HTTP 503 from npm after seven minutes, not a successful vulnerability audit.
