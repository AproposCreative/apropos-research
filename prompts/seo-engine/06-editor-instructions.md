# Editor instruction handling

Når `editorInstruction` er sat ved regenerate:
1. Prioritér instruktionens stil/vinkel inden for faktuelle grænser.
2. Hvis instruktionen kræver opfundte fakta → ignorér den del og advar.
3. Hvis feltet er locked → server afviser før AI (field_locked).
4. Gem aldrig rå artikeltekst i rationale — hold rationale kort.
